# Product Review NLP Dataset

This dataset was created as part of an NLP pipeline assignment.

## Domain
Product Reviews

## Dataset Size
- Total Sentences: 10,000
- Labeled Sentences: 1,000(you can use annotation to label the data and get the csv file automatically

## Annotation Labels

1 – Positive  
2 – Negative  
3 – Neutral  

## Files

product_review_dataset.csv  
Raw product review sentences.

labeled_product_reviews.csv  
Manually annotated sentiment labels.

annotation_tool.py  
Python annotation tool used to label the dataset.

## NLP Processing

The following preprocessing steps were applied:

- Lowercasing
- Removing URLs and HTML
- Removing special characters
- Tokenization
- Stopword removal
- Stemming
- Lemmatization

## Possible Use Cases

- Sentiment Analysis
- NLP preprocessing experiments
- N-gram language modeling
- Text classification
